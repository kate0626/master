# 全アクセス回数と、アクセス時点の各要素の分布

既存の `access_factors/` とは別の分析。前半・後半の観測窓に分割せず、
6グラフ × α=0.1/0.01 × 8始点のアクセス列全体を使う。ノードとエッジは混ぜない。

**まず [index.html](index.html) を開く。** 条件ごとに図を切り替えられる。
結果の文章は [RESULTS.md](RESULTS.md)、数値と再現確認は `data/`。

## 各要素は、他の要素とは別の情報を持つか？（現在の論点2）

[全体比較ページ](03_information_overlap/index.html)に、全12条件・ノード/エッジ別の3枚を掲載。

1. 全6ペアの要素間相関。
2. 全6ペアを両方向で比較する、1要素への追加による予測改善。
3. 残り3要素に各要素を加えたときの予測改善。

アクセス単位に統一し、初回と末尾100アクセスを除く共通母集団を使用。
7始点で学習し残り1始点で評価する比較を8通り実施する。
[方法](03_information_overlap/README.md)と[結果の数値](03_information_overlap/RESULTS.md)を併記。
以下に残す「論点2＝総回数との関係」「論点3＝条件付き比較」は、以前の番号に対応する図。

## まず見るサマリ図

**論点2は [相関係数のヒートマップ](00_summary/q2_correlation_heatmap.png)（[PDF](00_summary/q2_correlation_heatmap.pdf)）から見る。**
全アクセス回数とのSpearman順位相関を始点別に算出し、8始点で等重み平均。
赤＝正、青＝負、白に近い＝単調な関連が弱い。RはAの相関の符号を反転し、大きいほど最近という定義に合わせる。
4列ともアクセス単位。D・今回のH・O・Rを表示し、Rのみ初回アクセスを除く。
Oの列は定義上の重複を含むため印を付ける。セルのばらつきは `00_summary/q2_correlation_values.csv` の `sd_rho`。
非単調な関係は相関係数で見落とすため、下の中央値の図を併用する。

サマリ2は分布の中心を抜き出した図。分布幅は個別図、四分位点は `00_summary/q2_values.csv` に残す。
頻度Oは全回数Tと定義上重複するため、独立した有効性指標として表示しない。

## 論点2：よくアクセスされる対象は、どんな値を取るか

`01_total_distributions/` の横軸は**全体のアクセス回数 T**。
箱は25–75パーセンタイル、線は中央値、ひげは10–90パーセンタイル。
アクセス回数帯ごとに値の分布を比較する。平均値・相関だけで判断しない。

| パネル | 単位 | 縦軸 |
|---|---|---|
| ① | 始点×実体 | その回数帯にあるキーの個数 |
| ② | 始点×実体につき1点 | 次数D（ノード：隣接エッジ数、エッジ：両端点次数の平均） |
| ③ | 始点×実体につき1点 | その対象を初めてアクセスしたときの歩数H |
| ④ | アクセス1件につき1点 | 今回のRWでの歩数H |
| ⑤ | アクセス1件につき1点 | 今回のアクセス**直前**までの累積アクセス回数O |
| ⑥ | 再アクセス1件につき1点 | 前回アクセスから今回までのアクセス件数A |

- 時間は実時間ではなく、同じ始点のアクセス列の添字。直近性は `R=1/(1+A)`。
  図では読みやすい間隔Aで表示し、**小さいほど最近**と読む。
- 直近性は現在のアクセスで更新する前の値。初回は定義できないので欠測として除く。
- HはBFS距離ではない。③の初回歩数と④の今回の歩数も区別する。
- Oはキャッシュ内のカウンタではなく、列の先頭から数えた累積履歴。
- 全期間の頻度 `T / 列の長さ` はTと同じ情報なので、別の説明変数にはしない。
- **⑤は各キーでOが0〜T−1を一度ずつ取るという定義上の関係。Oの予測力を示す図ではない。**
- ④〜⑥は多くアクセスされる対象ほど多くの点を持つ。②③とは重みが違う。
  各帯の有効な件数nを表示する。図は始点をプールし、相関CSVは始点別に計算する。
- 母集団は1回以上アクセスされた対象。未訪問対象（T=0）は含めない。

## 論点3：他の要素をそろえても違いが残るか

TとOの定義上の重なりを「独立の予測情報」と誤認しないため、
`02_conditional_reuse/` ではアクセス時点の値と**次の再アクセス**を対応させる。

- 横軸：O/H/Dの値の帯。
- 色：もう一つの要素の小・中・大の層（各始点・型別の三分位）。同じ値は分割しない。
- 縦軸：次の100アクセス以内に同じ対象へ再アクセスした割合。
- 同じ横軸帯で色の線が分かれるなら、追加情報の候補となる。
- 6ペア（O×R、O×H、O×D、H×D、H×R、D×R）を折れ線で示す。
- 各始点の率を等重みで平均。帯は始点間の標準偏差で、信頼区間ではない。
  始点内セル20件以上、かつ有効3始点以上の点のみ描画する。
  線の欠落は「効果ゼロ」ではなく「表示条件を満たすデータが不足」。
- 層の実際の上下限・件数・再アクセス件数は `*_conditional_by_start.csv` に保存。
- 前半・後半の分割はしない。100は**予測を評価する先の長さ**であり、履歴を集計する観測窓ではない。
  Oは常にその時点までの全履歴。10/100/1000アクセス先の率をCSVに保存する。
- 各評価長より残りの列が短い末尾のアクセスは除く。観測が足りないものを「再訪なし」にしない。

**この層別図だけで独立性・因果・最適重みは決まらない。** 横軸帯内にも値の違いが残り、
表示していない他要素、歩行位置、始点による交絡もありうる。
また、対象は「今アクセスしたもの」であり、退去時の全キャッシュ候補ではない。
戻り歩行を含む再訪の統計で、実際のヒット率やLRUからの改善を測ったものではない。

## 再現

リポジトリのルートから：

```bash
python3 base/proposed_cache/figs/access_factors_distribution/analyze.py
python3 base/proposed_cache/figs/access_factors_distribution/build_report.py
```

一部だけ実行する場合：

```bash
python3 base/proposed_cache/figs/access_factors_distribution/analyze.py --graphs vldb enron --alphas 0.1 0.01
```

本家の歩行関数と既存のmeta JSONの始点・seed・歩行数・停止確率を使用。
各始点の全アクセス数、キー集合、キー別総回数・初回歩数・次数を既存keys CSVと照合し、
一致しなければ停止する。`*_manifest.json` に照合結果と入力SHA256を記録する。
既存の集計結果は書き換えない。追加依存は不要（既存のnumpy/matplotlibを使用）。
